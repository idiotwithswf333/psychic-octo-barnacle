KC32x DSi - proof of concept
Build:  install devkitPro (nds-dev group), then run `make` in this folder.
Run:    copy KC32x_DSi.nds to the SD card and launch via TWiLight Menu++ / hiyaCFW / Unlaunch.
Folder: the game creates /32xKC on the SD root if missing, and shows any .32x found there.
        (The ROM is only detected, not emulated. The gameplay is original placeholder code/art.)
